# M6 S3 — recorder screen, Record/Stop from the tray — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Implementer subagents run on **sonnet**; every per-task review and the final whole-branch review is a strict reviewer on **opus** (CLAUDE.md).

**Status of record:** `HANDOFF.md`. This plan carries no running status of its own. Progress is recorded there, and in `mindmap.md`, `README.md` and `apps/desktop/README.md` (AGENTS.md §11).

**Goal:** Land slice S3 of M6: a recorder screen in `packages/desktop-ui` (source, mic/system toggles, camera + bubble, Record), recording state in the tray (elapsed-time tooltip, Start/Stop item), Stop from the tray, and a 10 s screen + mic recording made from the app that plays.

**Architecture:** The engine gains two fixes the recorder flow needs: `Session::start` works from any resting state and is atomic, and window sources report a real size. The Tauri shell gains the write commands (`configure`, `start_recording`, ...) and a second engine subscriber, a tray observer thread that relabels the tray and closes/reopens the window as the session moves. Its decisions are pure functions behind a `TraySurface` trait, the same pattern `events.rs` uses. The webview replaces S2's diagnostic screen with four screens chosen from the session state. The window reads the engine's stored config and writes every change back, so the tray's "Start recording" records what the window shows.

**Tech Stack:** Rust 1.90+ (workspace floor), Tauri 2.12.4 (`tray-icon`), crossbeam-channel, serde_json (tests). TS 5.9.3, React 19.2.8, Tailwind 4.3.3, vitest 4.1.10, `@tauri-apps/api` 2.12.4, `@vrecnu/ui` (workspace).

**Spec:** `docs/superpowers/specs/2026-10-09-m6-tauri-shell-design.md`, slice S3 and decision D3. S1+S2 plan, for the conventions this one follows: `docs/superpowers/plans/2026-10-14-m6-s1-s2-tauri-shell.md`.

## Context

S1+S2 are on `main` (`595a1d5`, merged locally). The shell owns `Arc<Session>`, pumps `EngineEvent`s to the webview, and exposes read-only commands; the window shows a diagnostic dump. Nothing can record from the app yet.

Two engine defects stand between S2 and a working recorder. Both were found by reading `session.rs` and `wgc.rs` while writing this plan:

1. **A recording started from `Stopped` or `Failed` runs while every shell still shows the old state.** `Session::start` arms only from `Idle`, and the machine starts only from `Ready`. `transition` drops a refused move without a word, so `start` returns `Ok`, `spawn` launches the worker, and the state stays `Stopped`. The tray offers "Start recording" right after a recording finishes, so S3 would hit this on its second recording. `start` also checks the state under one lock and moves it under another, so two starts at once (a double click, or the window and the tray together) both pass and both spawn a worker.
2. **Window sources report 0x0** from `list_sources` (HANDOFF, S2 "Known"). The maintainer decided on 2026-10-15 to fix this in the engine as part of S3, not to work around it in the picker.

D3 settles the window: starting a recording closes it, so the vrecnu window is not recorded and no WebView2 renderer runs during a recording (the M9 RSS concern). Stopping reopens it. S3 reopens it on a minimal **Saved** screen (file, length, size, Show in folder, New recording). S4 replaces that screen with Review (`<video>`) and Publish.

## Review Focus

These five inputs and conditions follow from the spec but no slice test in it exercises them. Each is pinned by a test in the task that owns it:

1. **"Start recording" right after a recording finished, or after one failed.** Expected: the session shows Recording, the tray relabels, the window closes. Today the recording runs while the state stays `Stopped`. → Task 1 tests.
2. **Two starts at once** (a double-clicked Record, or Record in the window and "Start recording" in the tray together). Expected: exactly one recording; the second start gets "A recording is already running." → Task 1 concurrency test; Task 6 disables Record while a start is in flight.
3. **A remembered choice that no longer exists**: the chosen window has closed, the camera was unplugged, the microphone was removed. Expected: the window falls back to the primary screen, no camera and no microphone, and stores that, so neither Record nor the tray's "Start recording" fails on a stale id. → Task 5 `reconcileConfig` tests.
4. **Quit from the tray while recording.** Expected: the recording is stopped and FFmpeg finishes the file before the process exits, so the file plays. → Task 4 `wait_until` tests and the Task 7 hardware check.
5. **The window left open across Stop.** The user opens the window mid-recording and clicks Stop, or stops from the tray with the window open. Expected: the window lands on Saved with the finished file. The `stateChanged` event carries no recording, and two snapshot reads can return out of order. → Task 5 `needsResync` and `latestOnly` tests; Task 4 `window_action` test.

- [ ] **Step 4: Rewrite `start`.** Replace the whole `fn start` body (lines 446-482) with:

```rust
    fn start(&self) -> Result<SessionId> {
        // Everything fallible happens before the machine moves, so a failed start leaves the
        // session exactly where it was rather than in a Recording state with no worker.
        let id = SessionId(self.next_session.fetch_add(1, Ordering::Relaxed));
        let output = self.output_path(id)?;

        // One lock from the state check to the move into Recording. Checked under one lock and
        // moved under another, two starts at once (a double click, or the window and the tray
        // together) both passed the check and both spawned a worker.
        let mut inner = self.inner.lock();
        match inner.machine.state() {
            SessionState::Recording => {
                return Err(AppError::recoverable(
                    ErrorCode::IllegalState,
                    "A recording is already running.",
                ));
            }
            SessionState::Finalizing => {
                return Err(AppError::recoverable(
                    ErrorCode::IllegalState,
                    "The last recording is still being saved.",
                )
                .with_hint("Wait a moment, then start again."));
            }
            SessionState::Idle
            | SessionState::Ready
            | SessionState::Stopped
            | SessionState::Failed => {}
        }
        // Built and discarded, on purpose: it is the cheapest way to prove the configuration
        // can *become* a request — FFmpeg resolves, the data directory is writable — while the
        // session is still safely in its previous state. `spawn` builds the one that runs.
        // Called under the lock: the shell's path lookups never touch the session, so this
        // cannot deadlock, and releasing the lock here would reopen the race above.
        let _validated = self.build_request(&inner.config, output)?;

        // Replaced only once the start is certain. Replacing it earlier would orphan a running
        // worker's flag on a refused start, and `stop` could then never reach that worker.
        // Lock order is `inner` then `stop`; nothing takes them the other way round.
        *self.stop.lock() = Arc::new(AtomicBool::new(false));

        inner.session_id = Some(id);
        inner.elapsed_ms = 0;
        inner.stats = CaptureStats::default();
        inner.recording = None;
        inner.error = None;
        // Arm from any resting state, not only Idle. The machine starts only from Ready, and
        // `transition` drops a refused move without a word, so a recording started from Stopped
        // or Failed used to run while every shell still showed the old state.
        if inner.machine.state() != SessionState::Ready {
            self.transition(&mut inner, SessionState::Ready);
        }
        self.transition(&mut inner, SessionState::Recording);

        Ok(id)
    }
```

```rust
/// Where Windows parks a minimized window's rectangle.
const MINIMIZED_ORIGIN: i32 = -32_000;

/// A window's size, from its screen rectangle (`GetWindowRect`).
///
/// This is the outer frame. It includes the invisible resize borders (a few pixels a side on
/// Windows 10/11) that WGC does not capture, so it is a label for the picker, not the encode
/// size: the pipeline takes that from the first frame (HANDOFF, M2 wiring note 2). A minimized
/// window reports `0x0` rather than the taskbar stub Windows parks at `-32000`: its real size
/// is unknown until it is restored.
fn window_size(left: i32, top: i32, right: i32, bottom: i32) -> Size {
    if left <= MINIMIZED_ORIGIN && top <= MINIMIZED_ORIGIN {
        return Size {
            width: 0,
            height: 0,
        };
    }
    let span = |from: i32, to: i32| u32::try_from(to.saturating_sub(from)).unwrap_or(0);
    Size {
        width: span(left, right),
        height: span(top, bottom),
    }
}
```

```rust
//! What the tray shows, and when the window comes and goes, as the engine moves.
//!
//! Driven only by engine events, so a recording started from the window and one started from
//! the tray menu behave the same. The decisions are pure functions; the observer thread applies
//! them through [`TraySurface`], so none of this needs a tray or a webview to test.

use std::thread::JoinHandle;
use std::time::{Duration, Instant};

use crossbeam_channel::Receiver;
use vrecnu_shell_api::EngineEvent;
use vrecnu_types::SessionState;

/// The tray item that starts a recording.
pub(crate) const START_LABEL: &str = "Start recording";
/// The same item while a recording runs.
pub(crate) const STOP_LABEL: &str = "Stop recording";
const IDLE_TOOLTIP: &str = "vrecnu";

/// Everything the tray displays.
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct TrayView {
    pub(crate) tooltip: String,
    pub(crate) record_label: &'static str,
    pub(crate) record_enabled: bool,
}

/// What happens to the window on a state change (spec D3).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum WindowAction {
    /// Create the window, or focus it if it exists.
    Open,
    /// Destroy it: a recording must not capture vrecnu, and no renderer runs while recording.
    Close,
}

/// What the tray's Start/Stop item does in a given state.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum RecordAction {
    Start,
    Stop,
    Nothing,
}

/// Where the tray observer sends its decisions. A trait so the observer is testable.
pub(crate) trait TraySurface: Send + 'static {
    fn show(&self, view: &TrayView);
    fn window(&self, action: WindowAction);
}

pub(crate) fn tray_view(state: SessionState, elapsed_ms: u64) -> TrayView {
    match state {
        SessionState::Recording => TrayView {
            tooltip: format!("vrecnu - recording {}", format_elapsed(elapsed_ms)),
            record_label: STOP_LABEL,
            record_enabled: true,
        },
        // Disabled rather than relabelled: Stop has been pressed, and Start would be refused
        // until FFmpeg finishes the file.
        SessionState::Finalizing => TrayView {
            tooltip: "vrecnu - saving the recording".to_owned(),
            record_label: STOP_LABEL,
            record_enabled: false,
        },
        SessionState::Idle | SessionState::Ready | SessionState::Stopped | SessionState::Failed => {
            TrayView {
                tooltip: IDLE_TOOLTIP.to_owned(),
                record_label: START_LABEL,
                record_enabled: true,
            }
        }
    }
}

/// `m:ss`, or `h:mm:ss` from an hour up. The window's `formatElapsed` matches it.
pub(crate) fn format_elapsed(ms: u64) -> String {
    let total = ms / 1000;
    let (hours, minutes, seconds) = (total / 3600, total / 60 % 60, total % 60);
    if hours > 0 {
        format!("{hours}:{minutes:02}:{seconds:02}")
    } else {
        format!("{minutes}:{seconds:02}")
    }
}

pub(crate) fn window_action(from: SessionState, to: SessionState) -> Option<WindowAction> {
    match (from, to) {
        (_, SessionState::Recording) => Some(WindowAction::Close),
        // Back to the user with the result, or with why there is none.
        (
            SessionState::Recording | SessionState::Finalizing,
            SessionState::Stopped | SessionState::Failed,
        ) => Some(WindowAction::Open),
        _ => None,
    }
}

pub(crate) fn record_action(state: SessionState) -> RecordAction {
    match state {
        SessionState::Recording => RecordAction::Stop,
        SessionState::Finalizing => RecordAction::Nothing,
        SessionState::Idle | SessionState::Ready | SessionState::Stopped | SessionState::Failed => {
            RecordAction::Start
        }
    }
}

/// Whether FFmpeg may still be writing the file.
pub(crate) fn is_capturing(state: SessionState) -> bool {
    matches!(state, SessionState::Recording | SessionState::Finalizing)
}

/// Polls `done` until it holds or `timeout` passes. Returns whether it held.
pub(crate) fn wait_until(timeout: Duration, poll: Duration, mut done: impl FnMut() -> bool) -> bool {
    let deadline = Instant::now() + timeout;
    loop {
        if done() {
            return true;
        }
        if Instant::now() >= deadline {
            return false;
        }
        std::thread::sleep(poll);
    }
}

/// Follows the engine until it drops its sender, keeping the tray and the window in step.
pub(crate) fn spawn_observer(
    events: Receiver<EngineEvent>,
    initial: SessionState,
    surface: impl TraySurface,
) -> std::io::Result<JoinHandle<()>> {
    std::thread::Builder::new()
        .name("vrecnu-tray".into())
        .spawn(move || {
            let mut state = initial;
            let mut elapsed_ms = 0;
            let mut shown = tray_view(state, elapsed_ms);
            surface.show(&shown);
            for event in events {
                match event {
                    EngineEvent::StateChanged { from, to } => {
                        state = to;
                        if to == SessionState::Recording {
                            elapsed_ms = 0;
                        }
                        if let Some(action) = window_action(from, to) {
                            surface.window(action);
                        }
                    }
                    EngineEvent::Elapsed { ms } => elapsed_ms = ms,
                    _ => continue,
                }
                // `Elapsed` arrives at ~4 Hz and the tooltip changes once a second.
                let view = tray_view(state, elapsed_ms);
                if view != shown {
                    surface.show(&view);
                    shown = view;
                }
            }
        })
}
```

```rust
/// Installs the tray icon and its menu. Returns the Start/Stop item, which [`AppTray`]
/// relabels as the engine moves.
pub(crate) fn build(app: &AppHandle) -> tauri::Result<MenuItem<Wry>> {
    let open = MenuItem::with_id(app, OPEN, "Open vrecnu", true, None::<&str>)?;
    let record = MenuItem::with_id(app, RECORD, lifecycle::START_LABEL, true, None::<&str>)?;
    let quit = MenuItem::with_id(app, QUIT, "Quit", true, None::<&str>)?;

        .tooltip("vrecnu")
        .menu(&menu)
        // Left click opens the window; the menu is for right click.

        .on_menu_event(|app, event| match event.id.as_ref() {
            OPEN => window::open_main(app),
            RECORD => toggle_recording(app),
            QUIT => quit(app),
            _ => {}
        })
        .on_tray_icon_event(|tray, event| {
            if let TrayIconEvent::Click {
                button: MouseButton::Left,
                button_state: MouseButtonState::Up,
                ..
            } = event
            {
                window::open_main(tray.app_handle());
            }
        });
    if let Some(icon) = app.default_window_icon() {
        tray = tray.icon(icon.clone());
    }
    tray.build(app)?;
    Ok(record)

/// Starts with whatever the window last configured (the engine holds it), or the defaults if
/// the window was never opened.
fn toggle_recording(app: &AppHandle) {
    let session = session(app);
    let result = match lifecycle::record_action(session.snapshot().session) {
        RecordAction::Start => vrecnu_engine::spawn_session(&session).map(|_| ()),
        RecordAction::Stop => RecorderEngine::stop(session.as_ref()),
        RecordAction::Nothing => Ok(()),
    };
    // With the window closed, a notification is the only place this error can be seen.
    if let Err(err) = result {
        app.state::<Arc<TauriShell>>().notify(
            NotifyLevel::Error,
            "vrecnu could not record",
            &err.to_string(),
        );
    }

/// Quit during a recording stops it and lets FFmpeg finish the file first, so quitting never
/// leaves a half-written recording. The wait runs off the event loop, so the tray stays
/// responsive while it lasts.
fn quit(app: &AppHandle) {
    let session = session(app);
    if !lifecycle::is_capturing(session.snapshot().session) {
        app.exit(0);
        return;
    }
    if let Err(err) = RecorderEngine::stop(session.as_ref()) {
        tracing::warn!(%err, "could not stop the recording before quitting");
    }
    let handle = app.clone();
    let waiter = std::thread::Builder::new()
        .name("vrecnu-quit".into())
        .spawn(move || {
            let settled = lifecycle::wait_until(QUIT_GRACE, QUIT_POLL, || {
                !lifecycle::is_capturing(session.snapshot().session)
            });
            if !settled {
                tracing::warn!("quitting before the recording finished saving");
            }
            handle.exit(0);
        });
    if let Err(err) = waiter {
        tracing::warn!(%err, "could not wait for the recording to save");
        app.exit(0);
    }
}

/// The real [`TraySurface`]: the tooltip, the Start/Stop item and the main window. Tauri runs
/// these setters on the main thread itself, so calling them from the observer thread is safe.
pub(crate) struct AppTray {
    app: AppHandle,
    record: MenuItem<Wry>,
}

impl AppTray {
    pub(crate) fn new(app: AppHandle, record: MenuItem<Wry>) -> Self {
        Self { app, record }
    }
}

impl TraySurface for AppTray {
    fn show(&self, view: &TrayView) {
        let tooltip = self
            .app
            .tray_by_id(TRAY_ID)
            .map_or(Ok(()), |tray| tray.set_tooltip(Some(&view.tooltip)));
        for result in [
            tooltip,
            self.record.set_text(view.record_label),
            self.record.set_enabled(view.record_enabled),
        ] {
            if let Err(err) = result {
                tracing::warn!(%err, "could not update the tray");
            }
        }
    }

    fn window(&self, action: WindowAction) {
        match action {
            WindowAction::Open => window::open_main(&self.app),
            WindowAction::Close => window::close_main(&self.app),
        }
    }
```

```ts
/** "m:ss", or "h:mm:ss" from an hour up. Matches the tray tooltip (vrecnu-shell-tauri lifecycle.rs). */
export function formatElapsed(ms: number): string {
  const total = Math.floor(Math.max(0, ms) / 1000);
  const hours = Math.floor(total / 3600);
  const minutes = Math.floor(total / 60) % 60;
  const seconds = String(total % 60).padStart(2, "0");
  return hours > 0 ? `${hours}:${String(minutes).padStart(2, "0")}:${seconds}` : `${minutes}:${seconds}`;
}

const UNITS = ["KB", "MB", "GB", "TB"] as const;

/** Decimal units (1 KB = 1000 B), one decimal place from KB up. */
export function formatBytes(bytes: number): string {
  let value = Math.max(0, bytes);
  if (value < 1000) return `${value} B`;
  let unit: (typeof UNITS)[number] = "KB";
  for (const next of UNITS) {
    value /= 1000;
    unit = next;
    if (value < 1000) break;
  }
  return `${value.toFixed(1)} ${unit}`;
}

/** The last segment of a Windows or POSIX path. */
export function fileName(path: string): string {
  return path.split(/[\\/]/).pop() ?? path;
}
```

```ts
import type { AppError } from "./engine";

/**
 * Commands reject with the engine's AppError. Anything else (an unknown command, a closed IPC
 * channel) is a Tauri-level failure: wrapped so the UI renders one shape, and never marked as
 * having lost a recording it knows nothing about.
 */
export function toAppError(err: unknown): AppError {
  if (isAppError(err)) return err;
  const detail = err instanceof Error ? err.message : String(err);
  return {
    code: "INTERNAL",
    message: "vrecnu could not reach its engine.",
    hint: "Close the window and open it again from the tray.",
    detail,
    recoverable: true,
    sessionLost: false,
  };
}

function isAppError(value: unknown): value is AppError {
  if (typeof value !== "object" || value === null) return false;
  const record = value as Record<string, unknown>;
  return typeof record.code === "string" && typeof record.message === "string" && typeof record.sessionLost === "boolean";
}
```

```ts
import type { AudioDevices, CameraInfo, CaptureSource, SessionConfig } from "./engine";

export interface Devices {
  sources: CaptureSource[];
  cameras: CameraInfo[];
  audio: AudioDevices;
}

/** The primary screen first, then other screens, then windows by title. */
export function orderSources(sources: CaptureSource[]): CaptureSource[] {
  const rank = (s: CaptureSource) => (s.kind === "monitor" ? (s.isPrimary ? 0 : 1) : 2);
  return [...sources].sort((a, b) => rank(a) - rank(b) || a.title.localeCompare(b.title));
}

/** A minimized window has no known size (the engine reports 0x0), so none is shown. */
export function sourceLabel(source: CaptureSource): string {
  const primary = source.isPrimary ? " - primary" : "";
  const size = source.size.width > 0 ? ` (${source.size.width}×${source.size.height})` : "";
  return `${source.title}${primary}${size}`;
}

/**
 * Drops choices this machine can no longer honour: a closed window, an unplugged camera, a
 * removed microphone. Kept, they fail at Record, or worse from the tray, with an error the user
 * cannot connect to a choice made earlier.
 */
export function reconcileConfig(config: SessionConfig, devices: Devices): SessionConfig {
  const fallback = orderSources(devices.sources)[0]?.id ?? null;
  const source = devices.sources.some((s) => s.id === config.source) ? config.source : fallback;
  const camera = devices.cameras.some((c) => c.id === config.camera) ? config.camera : null;
  const microphone = devices.audio.inputs.some((d) => d.id === config.microphone) ? config.microphone : null;
  return {
    ...config,
    source,
    camera,
    microphone,
    systemAudio: config.systemAudio && devices.audio.outputs.length > 0,
    bubble: camera === null ? null : config.bubble,
  };
}
```

```ts
/**
 * A state change is the event whose consequences the reducer cannot see: Stopped arrives
 * without the recording, Recording without the reset counters. The snapshot has both, so the
 * hook re-reads it after every state change, a handful per recording.
 */
export function needsResync(event: EngineEvent): boolean {
  return event.type === "stateChanged";
}

export type Screen = "recorder" | "recording" | "saved" | "failed";

export function screenFor(app: AppState): Screen {
  switch (app.session) {
    case "idle":
    case "ready":
      return "recorder";
    case "recording":
    case "finalizing":
      return "recording";
    case "stopped":
      return "saved";
    case "failed":
      return "failed";
  }
}

/**
 * Only the most recently started read is delivered. Ready -> Recording and Finalizing ->
 * Stopped can each trigger a re-read within milliseconds, and the replies can cross; applying
 * an older snapshot last would strand the window on the earlier state.
 */
export function latestOnly<T>(read: () => Promise<T>, deliver: (value: T) => void): () => Promise<void> {
  let latest = 0;
  return async () => {
    const ticket = ++latest;
    const value = await read();
    if (ticket === latest) deliver(value);
  };
}
```

```ts
import { useEffect, useReducer } from "react";
import { initialStore, latestOnly, needsResync, reduce, type Store } from "./state";
import { getSnapshot, onEngineEvent } from "./tauri";

/**
 * Listens first, then reads the snapshot: an event landing in between is buffered, not lost.
 * Re-reads the snapshot after every state change (see `needsResync`).
 */
export function useEngine(): Store {
  const [store, dispatch] = useReducer(reduce, initialStore);
  useEffect(() => {
    let cancelled = false;
    let unlisten: (() => void) | undefined;
    const sync = latestOnly(getSnapshot, (state) => {
      // A cleanup landing while the snapshot was in flight must not apply it to a newer mount.
      if (!cancelled) dispatch({ kind: "snapshot", state });
    });
    const resync = () => {
      sync().catch((err: unknown) => console.error("vrecnu: could not read the engine state", err));
    };
    onEngineEvent((event) => {
      dispatch({ kind: "event", event });
      if (needsResync(event)) resync();
    })
      .then((stop) => {
        if (cancelled) return stop();
        unlisten = stop;
        resync();
      })
      .catch((err: unknown) => console.error("vrecnu: could not connect to the engine", err));
    return () => {
      cancelled = true;
      unlisten?.();
    };
  }, []);
  return store;
}
```

```tsx
      .then(() => startRecording())
      .catch((err: unknown) => {
        setError(toAppError(err));
        setStarting(false);
      });
  };

  return (
    <form
      className="flex flex-col gap-5"
      onSubmit={(event) => {
        event.preventDefault();
        record();
      }}
    >
      <label className="flex flex-col gap-1 text-sm">
        <span className="text-slate-300">Record</span>
        <select
          className={FIELD}
          value={config.source ?? ""}
          disabled={sources.length === 0}
          onChange={(event) => change({ source: event.target.value })}
        >
          {sources.length === 0 && <option value="">No screens found</option>}
          <optgroup label="Screens">
            {monitors.map((s) => (
              <option key={s.id} value={s.id}>
                {sourceLabel(s)}
              </option>
            ))}
          </optgroup>
          {windows.length > 0 && (
            <optgroup label="Windows">
              {windows.map((s) => (
                <option key={s.id} value={s.id}>
                  {sourceLabel(s)}
                </option>
              ))}
            </optgroup>
          )}
        </select>
      </label>

      <fieldset className="flex flex-col gap-2 text-sm">
        <legend className="mb-1 text-slate-300">Sound</legend>
        <Toggle
          label={mic ? "Microphone" : "Microphone (none found)"}
          checked={config.microphone !== null}
          disabled={mic === null}
          onChange={(on) => change({ microphone: on && mic ? mic.id : null })}
        />
        <Toggle
          label={hasOutput ? "System audio" : "System audio (no output device)"}
          checked={config.systemAudio}
          disabled={!hasOutput}
          onChange={(on) => change({ systemAudio: on })}
        />
      </fieldset>

      <fieldset className="flex flex-col gap-2 text-sm">
        <legend className="mb-1 text-slate-300">Camera</legend>
        <select
          className={FIELD}
          value={config.camera ?? ""}
          onChange={(event) => {
            const camera = event.target.value === "" ? null : event.target.value;
            change({ camera, bubble: camera === null ? null : config.bubble });
          }}
        >
          <option value="">No camera</option>
          {devices.cameras.map((c) => (
            <option key={c.id} value={c.id}>
              {c.name}
            </option>
          ))}
        </select>
        <Toggle
          label="Show the camera bubble on screen"
          checked={config.bubble !== null}
          disabled={config.camera === null}
          onChange={(on) => change({ bubble: on ? DEFAULT_BUBBLE : null })}
        />
      </fieldset>

      {error && <ErrorNote error={error} />}

      <Button
        type="submit"
        variant="destructive"
        size="lg"
        className={DANGER}
        disabled={starting || config.source === null}
      >
        {starting ? "Starting…" : "Record"}
      </Button>
    </form>
  );
}

function Toggle({
  label,
  checked,
  disabled,
  onChange,
}: {
  label: string;
  checked: boolean;
  disabled: boolean;
  onChange: (on: boolean) => void;
}) {
  return (
    <label className={`flex items-center gap-2 ${disabled ? "text-slate-500" : "text-slate-100"}`}>
      <input
        type="checkbox"
        className="size-4 accent-red-600"
        checked={checked}
        disabled={disabled}
        onChange={(event) => onChange(event.target.checked)}
      />
      {label}
    </label>
  );
}
```
